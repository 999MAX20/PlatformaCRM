продолжая независимую разрешённую работу.

## Как закрывать

Указать новый результат, точную версию, изменённые входы, среду, команды и evidence.
Backend требует happy/invalid, permissions/tenant, applicable lifecycle/money/
rollback/concurrency/replay/recovery; user-facing — доступный flow. Full gate
нужен для release candidate или согласованной общей сертификации, не каждой
docs-задачи. Working DB и live provider не входят в isolated tests.

Не переносить checkbox PASS без применимого evidence и неизменных входов.
Не скрывать failure, но и не переносить исправленный исторический failure в
текущий статус. Если статус отдельного старого ID не установлен, писать
«evidence не сверено», а не «код отсутствует» или «готово».
