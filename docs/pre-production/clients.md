## Работа пользователя и данные

Список/поиск → карточка → контакты, заметки, история и доступные связанные заявки,
сделки, записи, задачи и переписка. Контакт не заменяет отдельную потребность Lead.
Карточка собирает реальные scoped-проекции, а не выдаёт доступ ко всем дочерним данным.
Custom fields сохраняют тип, ограничения и видимость; текущая приёмка их потребителей
описана в [Settings evidence](../testing/settings-functional-20261008.md).

Duplicate preview использует нормализованные телефон/email и channel identity.
Совпадение имени не является основанием для merge. Подтверждённое объединение
переносит связи и денежный журнал, сохраняет ClientMergeLog и архивирует дубль.
Возврат из архива не отменяет результаты сделок/визитов и не является undo merge.

## Права, ошибки и восстановление

Business и object scope обязательны. AUD-02 устраняет foreign links/подмену
авторства notes/activity: проверяются прямые и polymorphic CRM-связи, автор из
сессии, прежняя связь при relink. Версия и проверки — checkpoint AUD-02-20261017.
AUD-03 закрывает выдачу Client.notes через list/detail, карточки, segment evaluate,
public token и CSV. Оператор получает пустое поле; owner/разрешённая роль — значение.
Пустой masked edit сохраняет исходную заметку, непустая запрещённая запись даёт 403.
Notes-сегменты скрываются вместе с условиями/счётчиками. Версия, изолированные
API-проверки и граница публикации — checkpoint AUD-03-20261017; deployment отдельно.
Generic API не обеспечивает контракт
по всем входам; [evidence](../testing/project-audit-20261017.md) и
[очередь исправлений](../current/roadmap.md#project-audit-20261017).
Archive/soft DELETE/merge требуют `clients:delete`, а не update. Архивация проверяет
незавершённые заявки/сделки/визиты/Inbox и прямые/косвенные задачи, включая скрытые
от пользователя зависимости. Конфликт требует разобраться с работой, не удалить её.
AUD-11 исправлен29.10: общая транзакция merge API включает сервис с блокировкой
Business/клиентов, перенос связей/ledger, архив, историю и request audit. Сбой до или
после вставки audit откатывает всё; повтор после сбоя создаёт одно объединение.
Кандидат54 теста/system/drift PASS; команды, версия и публикация — AUD-11 в PRIMARY.
Обычный пользователь не получает hard-delete как способ исправления дублей.
