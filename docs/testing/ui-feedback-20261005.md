## Результат

Причиной розовых/персиковых карточек были **действующие**, а не забытые старые
алиасы: версия 1 общего JSON содержала warning.soft `#FFF5E8` и danger.soft
`#FFF0EE`. В версии 2 оба значения заменены на нейтральный surface.subtle

Действия StatusNotice центрируются по высоте рядом с текстом на широком экране
и по горизонтали под текстом на узком. Закрытие toast остаётся в углу, повторное
действие — по центру снизу. Уведомление о непрочитанных сообщениях использует
тот же компонент; кнопки открытия/закрытия сохраняют прежние обработчики.

В EN/KK русский fallback стоял после части переводов и перезаписывал их.
Он перенесён перед переводами; проверка i18n теперь обнаруживает этот порядок.
Сообщения о временном сбое и потере связи упрощены на RU/KK/EN: убраны техническая
формулировка про сервер и недоказанное обещание, что изменения точно сохранены.

## Когда показываются

| Ситуация | Что видит пользователь | Следующее действие |
| --- | --- | --- |
| Сбой загрузки профиля / восстановления сессии | ErrorState или предупреждение поверх рабочей страницы | Повторить; сохраняется исходный маршрут |
| Временный сбой загрузки / операции | InlineFallback, ErrorState или toast | Разрешённая повторная попытка; проверка результата |
| Потеря сети / восстановление связи | ConnectivityBanner | Проверить связь, повторить после восстановления |
| Истёкшая сессия | Сообщение authentication | Повторный вход; не слепой повтор операции |
| Недостаточно прав / отключённый раздел | ForbiddenState / PermissionFallback | Обратиться к владельцу или администратору |
| Запись удалена или недоступна | Сообщение not_found / страница ошибки | Вернуться к актуальному списку |
| Запись изменилась, конфликт времени или состояния | Сообщение conflict | Обновить данные и проверить изменения |
| Слишком много попыток | Сообщение rate_limit | Подождать; соблюдать политику повторения |
| Внешний сервис / AI недоступен | Предупреждение provider / AI | Проверить состояние, продолжить доступную ручную работу |
| Неверные поля формы | Input/Select/Textarea errors, FieldErrorSummary, локальные alert | Исправить отмеченные поля |
| Неожиданный сбой страницы или приложения | RouteErrorView / AppErrorBoundary | Обновить, вернуться назад или в рабочую область |
| Успешное сохранение / завершение | Success toast / StatusNotice | Продолжить работу |
| Обратимое действие | UndoToast | Отменить действие в доступное время |
| Непрочитанное сообщение | Уведомление в Header | Открыть непрочитанные сообщения или закрыть карточку |
| Загрузка / отсутствие записей | LoadingState, PageSkeleton, EmptyState | Дождаться данных, создать запись или изменить фильтр |
| Результат записи оплаты пока не подтверждён | Предупреждение payments.uncertain | Проверить тот же результат, избежать дублирования |
| Приоритет, статус записи, показатель или AI-сигнал | Badge, StatusBadge, Card, AiInsightCard | Прочитать статус, открыть соответствующий контекст |

Точное условие/обработчик и ключи текста для каждого найденного использования
приведены в подробном реестре. Часть InlineFallback/FieldErrorSummary существует
как общая инфраструктура и в тестовых сценариях, но не имеет прямых production
JSX-вызовов; это явно видно по нулю в таблице, а не скрыто за общим счётчиком.
