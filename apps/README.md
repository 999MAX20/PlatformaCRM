# Backend PlatformaCRM

Фактические приложения находятся в этом каталоге; регистрация — в
[settings](../config/settings.py), маршруты — в [urls](../config/urls.py).
Business tenant, backend permissions и domain services обязательны.
Не считать AI/bots/integrations «планируемыми» только по старому README:
код существует, а live-допуск и активный scope — отдельные вопросы.

Для работы: [карта модулей](../docs/pre-production/capabilities.md),
[CRM](../docs/current/crm.md), [доступ](../docs/current/access.md),
[инженерные правила](../docs/current/engineering.md),
[изолированные проверки](../docs/testing/testing.md).
